# Employee API: Draft Contract (v0.1, DRAFT)

Base URL (local): `http://localhost:8000`
Interactive docs: `http://localhost:8000/docs`
Format: JSON. Endpoints may change; this is a draft for other teams to start planning.

## Endpoints

| Method | Path                | Purpose                          | Request body        | Success response            | Status |
|--------|---------------------|----------------------------------|---------------------|-----------------------------|--------|
| GET    | `/health`           | Check the service is running     | none                | `{"status": "ok"}`          | Live   |
| GET    | `/employees`        | List employees (paged, filters)  | none                | `{"items": [Employee], "total": int}` | Planned |
| GET    | `/employees/{id}`   | Get one employee                 | none                | `Employee`                  | Planned |
| POST   | `/employees`        | Create an employee               | `EmployeeCreate`    | `Employee` (201)            | Planned |
| PUT    | `/employees/{id}`   | Update an employee               | `EmployeeCreate`    | `Employee`                  | Planned |
| DELETE | `/employees/{id}`   | Delete an employee               | none                | 204 No Content              | Planned |

Planned query parameters for `GET /employees`: `page`, `page_size`, `department`, `status`.

## Employee object

| Field        | Type    | Notes                                   |
|--------------|---------|-----------------------------------------|
| `id`         | integer | Generated by the server                 |
| `first_name` | string  | Required                                |
| `last_name`  | string  | Required                                |
| `email`      | string  | Required, unique                        |
| `department` | string  | e.g. Engineering, HR, Finance           |
| `job_title`  | string  |                                         |
| `hire_date`  | date    | Format `YYYY-MM-DD`                     |
| `status`     | string  | One of `active`, `inactive`, `on_leave` |

## Errors

Errors use a standard shape: `{"detail": "message"}` with codes 400, 404, 422 (validation), 500.
